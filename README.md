# Gestion commerciale Android

Une application Android hors ligne en langue arabe pour les petits commerces.

## Fonctionnalités prévues
- Tableau de bord
- Produits, prix et stock
- Ventes et mise à jour automatique du stock
- Dépenses et bénéfices
- Rapports simples

## Technologies
- Kotlin
- Jetpack Compose
- Room
- Architecture MVVM

## Intégration Harness
Ce dépôt contenait déjà les fichiers Harness/AI : `app.py`, `dockerfile` et `script.sh`.
Le projet Android est ajouté sur la branche `feature/arabic-shop-manager` sans suppression des fichiers existants.
